# RoScaper Launcher

Кастомный, стильный и быстрый лаунчер для Minecraft, созданный для максимально комфортной игры. Никаких сложных настроек, вылетов и лишних кнопок — только красивый интерфейс, стабильность и скорость.

---

## Особенности лаунчера

*   **Современный дизайн:** Красивый интерфейс со стеклянным эффектом (Glassmorphism), плавными анимациями и умными приветствиями, которые меняются в зависимости от времени суток.
*   **Надежная загрузка:** Встроенная система защиты от сетевых сбоев. Лаунчер скачивает тысячи ресурсов игры стабильно, аккуратно и без вылетов.
*   **Живая статистика:** Забудьте про зависшие полоски загрузки! RoScaper показывает точный прогресс: проценты, количество скачанных файлов и мегабайты в реальном времени.
*   **Всё работает "из коробки":** Больше не нужно гуглить и устанавливать Java вручную. Лаунчер сам определит, незаметно скачает и настроит правильную версию Java (8 или 17) для вашей версии Minecraft.
*   **Безопасность и чистота:** Игра устанавливается в собственную изолированную директорию. Она никогда не конфликтует с официальным клиентом или другими сборками на вашем ПК.
*   **Удобные настройки:** Настройка выделения оперативной памяти (ОЗУ) в пару кликов, полноэкранный режим и удобная кнопка быстрого доступа к папке игры (идеально для быстрой установки модов, шейдеров и ресурспаков).

* Скачать лаунчер можно в оффициальном телеграм канале розработчика -- t.me/RoScaperClient.
